Introduction

Your personal AI knowledge companion for iOS, iPadOS, and macOS.

NestMind is a digital knowledge companion that helps you save, organize, search, and discover information using on-device AI and semantic understanding.

ℹ️
Privacy First
All AI processing happens on your device. No cloud services, no external API calls, complete privacy.

Key Features

  • Semantic Search - Find by meaning, not keywords
  • AI Assistant - Chat with your knowledge base using Apple Intelligence
  • Smart Library - Automatically categorized bookmarks and resources
  • Task Management - Integrated todos linked to your knowledge
  • CloudKit Sync - Seamless sync across all your devices

Quick Start

Get started with NestMind in under 5 minutes.

Requirements

  • iOS 26.0+, iPadOS 26.0+, or macOS 15.0+
  • Apple Intelligence enabled
  • Xcode 16+ (for development)

First Run

  1. Download NestMind from the App Store
  2. Complete the onboarding flow
  3. Start saving your first bookmark or todo
  4. Try semantic search to find what you saved

Semantic Search

NestMind's semantic search understands meaning, not just keywords.

How It Works

Semantic search uses on-device embeddings to understand the meaning of your content:

swift 
// Semantic search implementation
let results = await semanticSearch.search(
    query: "iOS development best practices",
    items: bookmarks,
    textFields: [\.title, \.notes, \.url]
)

// Results ranked by semantic similarity
for bookmark in results {
    print("📚 \(bookmark.title)")
    print("   Score: \(bookmark.score)")
}
💡
Pro Tip
Semantic search finds relevant results even if they don't contain your exact search terms. Try searching for concepts, not keywords.

AI Assistant

Chat with your knowledge base using Apple Intelligence.

Foundation Models Integration

The AI Assistant uses Apple's Foundation Models framework for on-device processing:

swift 
// AI Assistant with Foundation Models
@Observable class AssistantViewModel {
    let session: FoundationModelSession

    func ask(_ query: String) async {
        for try await token in session.stream(query) {
            handleToken(token)
        }
    }
}

Smart Routing

The assistant automatically routes queries to the right context:

  • Knowledge queries → Search your bookmarks and notes
  • General questions → Use Foundation Models directly
  • Task commands → Create or manage todos
